昆虫标本工作台 Windows x64 便携版
==================================

系统要求
--------
- Windows 10 或 Windows 11，64 位
- 可访问模型 API 的网络连接
- 约 500 MB 可用磁盘空间

开始使用
--------
1. 请先完整解压 ZIP，不能直接在压缩包内运行。
2. 把文件夹放在桌面或其他可写目录，不要放入 Program Files。
3. 双击“启动昆虫标本工作台.bat”。
4. 首次启动时设置管理员用户名和至少 12 位的密码。
5. 等待浏览器自动打开 http://127.0.0.1:8000。
6. 登录后进入“设置”配置模型 API。
7. 在“模板与导出”上传当前用户的 Excel 模板。

停止程序
--------
关闭启动窗口，或在窗口中按 Ctrl+C。仅关闭浏览器不会停止服务。

数据与升级
----------
- 数据库、模板、图片、素材和导出文件保存在 data 文件夹。
- 管理员初始化配置保存在 .env 文件。
- 请定期备份整个 data 文件夹和 .env。
- 升级时先停止程序，将旧版 data 和 .env 复制到新版文件夹。
- 不要把 .env 发给其他人，其中包含首次管理员配置。

安全说明
--------
- 服务只监听本机 127.0.0.1，不会主动开放局域网端口。
- 密码使用 Argon2 哈希存入数据库。
- 请从项目 GitHub Release 下载，并核对发布页提供的 SHA-256。

故障排查
--------
- 提示端口 8000 被占用：关闭其他昆虫标本工作台、Docker 容器或占用进程。
- 浏览器未自动打开：手动访问 http://127.0.0.1:8000。
- Windows SmartScreen 提示：确认文件来自项目 GitHub Release 后，选择“更多信息”。
- 目录不可写：把整个文件夹移动到桌面或文档目录后重试。
